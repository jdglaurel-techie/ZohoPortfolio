Automation and approval architecture across the whole org

Beyond any single module, the org runs a layered automation stack: Workflow Rules for event-driven actions, Blueprints for stage-gated processes, and multi-level Approval Processes for anything that needs a human decision. All of it was built and is maintained in-house.

Workflow Rules

Rules firing across Opportunities, Sales Invoice, Sales Order, Cash Advance, Trip Tickets, Asset Management, the Ticketing System and HR records — field updates, alerts, and custom function calls.

Blueprints

Stage-gated processes on Leads, Companies, Tasks, Cases and Sales Order, each with entry criteria, transitions and validation at every step.

Approval Processes

Two-tier GM and President approvals across Purchase Requisition, Purchase Orders, Payment Request, Cash Advance, Job Orders and Opportunities — including multi-level chains such as Opportunity Level 1 and Level 2.

Opportunities

96 active fields (74 custom), 2 subforms. A full quotation/bid pipeline: Receipt of Inquiry, Pre-Bid Survey, Technical and Commercial Proposal, Solution Design, with Incoterms and payment terms.

Order Intake

68 fields (54 custom). Picks up a won opportunity and tracks the confirmed order: PO details, delivery dates, gross profit per business unit, and sales-credit splits.

Sales Invoice

38 fields (24 custom). Invoice and due dates, TIN, tax code, VAT 12%, aging and collection date: one source of truth from PO to collection.

Zoho Analytics dashboards on the Opportunities → Order Intake → Sales Invoice chain give management pipeline value, order GP by business unit and invoice aging without a separate BI tool.

Automated Lead Intake: web form → n8n → Zoho CRM

A self-hosted automation that turns a web enquiry into a Zoho CRM Lead with no manual encoding. Built end to end on free-tier infrastructure, including the OAuth handling and the production troubleshooting.

Least-privilege OAuth

The token is scoped to ZohoCRM.modules.leads.CREATE,READ only, so even a copied workflow cannot touch another module or delete a record.

Automatic token refresh

Refreshing was moved out of the main flow into a dedicated "Zoho Token Refresh" sub-workflow using the refresh token grant, so the automation keeps running unattended instead of breaking when the access token expires.

AI lead triage with Gemini

An AI Agent node backed by Google Gemini turns a freeform enquiry into structured category, urgency and summary fields, which are written into the Lead's Description so sales can prioritise without reading every message. Live run: "CRM automation", urgency high.

Real payload debugging

JotForm delivers answers as an escaped JSON string inside rawRequest, so the field mapping was derived by inspecting the actual webhook payload rather than guessing at field names.

Production troubleshooting

The free 512 MB instance crash-looped with a JavaScript heap out-of-memory error, surfacing as a 502. Fixed by capping the Node heap with NODE_OPTIONS=--max-old-space-size=460. When the same failure reappeared later, the cause was that the variable had gone missing after a redeploy, so verifying it after every deploy became part of the runbook.
